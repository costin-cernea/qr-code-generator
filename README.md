# 📱 QR Code Generator | QuickTools

![Language](https://img.shields.io/badge/Language-JavaScript-yellow)
![Style](https://img.shields.io/badge/Style-CSS3-blue)
![License](https://img.shields.io/badge/License-MIT-green)

A lightweight, fast, and privacy-focused web tool to generate custom QR codes instantly. Built with **Vanilla JavaScript**, this tool allows users to convert text or URLs into scannable images and download them directly.

Part of the **QuickTools** utility suite.

🔗 **Live Demo:** [CLICK HERE TO VIEW](https://costin-cernea.github.io/qr-code-generator/)

---

## ✨ Key Features

* **⚡ Instant Generation:** Renders QR codes in real-time as you type or upon clicking generate.
* **⬇️ Download Capability:** Export your generated QR code as a high-quality PNG image with a single click.
* **🌗 Smart Dark Mode:** Automatically detects system preferences (mobile/desktop) and includes a manual toggle switch.
* **📱 Fully Responsive:** Optimized layout for seamless use on Mobile, Tablet, and Desktop.
* **🔗 Integrated Ecosystem:** Features a dropdown navigation menu to easily switch between this tool and the **Password Generator**.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure.
* **CSS3:** Modern styling with Custom Properties (Variables) for theming.
* **JavaScript (ES6+):** Logic for DOM manipulation, theme switching, and download handling.
* **Library:** `qrcode.js` (for QR rendering).

## 🚀 How to Run Locally

Since this is a static project, you don't need to install complex dependencies.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/costin-cernea/qr-code-generator.git
    ```
2.  **Open the project:**
    Navigate to the folder and open `index.html` in your favorite browser.
